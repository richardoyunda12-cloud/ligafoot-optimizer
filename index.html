❓ Panduan Setup Client ID Google Cloud (1x saja, ~2 menit, gratis)
  1. Buka Google Cloud Console → buat proyek baru (mis. LigaFootSync).
  2. Menu APIs & Services → Library → cari & klik Enable pada Google Drive API.
  3. Menu Google Auth platform / OAuth consent screen → pilih External → isi nama app & email → di bagian Audience / Test users tambahkan email Gmail kamu sendiri (status biarkan Testing agar langsung jalan tanpa verifikasi Google).
  4. Menu Clients → Create OAuth client ID → Web application → di Authorized JavaScript origins isi persis: https://richardoyunda12-cloud.github.io
  5. Salin Client ID (...apps.googleusercontent.com) ke kolom di atas, lalu klik 📁 Cari Folder (atau tempel URL folder Google Drive tempat kamu rutin menaruh save).
  6. Klik 🔗 Salin Link untuk HP Lain lalu buka link itu di HP lain — beres, tanpa ketik ulang!
